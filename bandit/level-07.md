# Bandit Level 7 → Level 8

## Goal

Find the password in `data.txt` on the line containing the word `millionth`.

## Concept

`grep` searches a file's contents for a word or pattern and displays the matching lines.

## Commands Used

```bash
grep "millionth" data.txt
```

## What I Did

I used `grep` to search `data.txt` for `millionth`, returning the line containing the password.

## What I Learned

This challenge reinforced the distinction between `find`, which locates files, and `grep`, which searches their contents without displaying the entire file.
