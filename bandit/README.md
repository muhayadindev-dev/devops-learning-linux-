# OverTheWire Bandit Walkthroughs

**Section:** Bandit Walkthroughs · [Repository Home](../README.md) · [Linux Cheat Sheet](../linux-cheatsheet/README.md)

A record of my progress through the OverTheWire Bandit challenges, where I put my Linux fundamentals to the test through practical command-line exercises.

## Overview

Bandit is a Linux command-line wargame where each level presents a different problem. Completing a challenge provides the credentials needed to access the next level.

The challenges begin with basic file navigation and gradually introduce searching, permissions, text processing, encoding, compression and networking.

## Objective

I used Bandit to challenge my understanding of Linux fundamentals and put what I'd learned into practice.

Each level required me to understand the problem, identify the appropriate commands and apply them to reach a solution. As the challenges became more involved, I started combining different tools and applying concepts from earlier levels.

This repository documents my completed solutions, explains the commands involved and highlights what I learned from each challenge.

## Skills Developed

| Area | What I Practised |
|---|---|
| File Navigation | Absolute and relative paths, hidden files and unusual filenames |
| Permissions and Ownership | File permissions, ownership, groups and restricted access |
| Searching | Using `find` and `grep` to locate files and search their contents |
| Data Processing | Pipes, redirection, `sort`, `uniq` and `strings` |
| Encoding and Decoding | Base64, ROT13 and reconstructing binary data from hexdumps |
| Compression and Archives | Identifying and extracting gzip, bzip2 and tar files |
| SSH and Networking | Remote access, private-key authentication, Netcat and TLS |

## Disclaimer

These walkthroughs document the commands, approaches and concepts I used to complete each challenge. They include solutions and explanations but exclude passwords and private-key contents.

I recommend attempting each challenge independently before reading the walkthroughs.
